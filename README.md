# Service Management System 🚀
A DSA-based project that simulates a Service Management System using core concepts of Data Structures and Algorithms. This project implements Graph Traversal and Dijkstra’s Algorithm in C++ to manage and optimize service routes efficiently.

📌 Project Overview
This system models a network of service points (nodes) and connections (edges) to determine the most efficient service routes. It supports real-time pathfinding and distance calculation, ideal for delivery, logistics, or customer support dispatch systems.

🛠️ Technologies & Tools Used
Language: C++

DSA Concepts: Graphs, Priority Queues, Adjacency Lists

Algorithms:

Dijkstra’s Algorithm (Shortest Path Finder)

Graph Traversal (BFS/DFS if included)

⚙️ Features
Represent service centers and routes as a graph.

Compute the shortest path between service points using Dijkstra’s Algorithm.

Real-time query support for optimal path discovery.

Dynamic input for network creation and analysis.

🧠 Learning Outcomes
Applied real-world graph algorithms in service management.

Strengthened understanding of C++ data structures and OOP.

Developed a command-line utility with interactive inputs and clear outputs.
